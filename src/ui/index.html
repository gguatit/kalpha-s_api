API 서비스

다양한 유틸리티 API를 테스트하고 사용할 수 있습니다.

API 문서 보기

IP 정보 확인

전체 IP 정보 (GET /ip)

접속한 클라이언트의 상세 IP 정보를 JSON 형식으로 반환합니다.


        

        

          
단순 IP 주소 (GET /ip/simple)

          
클라이언트의 IP 주소만 평문(텍스트)으로 반환합니다.

          
          

        

      

    


    
    

      
데이터 변환 (Base64)

      

        

          
인코딩 (GET /encode)

          
문자열을 Base64 형식으로 변환합니다.

          

            
            
          

          

        

        

          
디코딩 (GET /decode)

          
Base64 문자열을 원본 문자로 복원합니다.

          

            
            
          

          

        

      

    


    
    

      
QR 코드 생성

      

        
텍스트 기반 QR 생성 (GET /qr)

        
입력한 데이터를 바탕으로 SVG 형식의 반응형 QR 코드를 즉시 생성합니다.

        

          
          
        

        

      

    


    
    

      
보안 메시지 (Dead Drop)

      
한 번 읽으면 영구적으로 삭제되는 일회성 메시지를 생성하고 조회합니다.

      

        

          
메시지 저장 (POST /store)

          
내용을 암호화하여 서버에 임시 저장하고 고유 ID를 발급받습니다.

          

            
            
          

          

        

        

          
메시지 열람 (GET /read/:id)

          
발급받은 ID를 통해 보관된 메시지를 열람합니다. (열람 즉시 파기)

          

            
            
          

          

        

      

    


    
    

      
보안 도구 및 시스템

      

        

          
보안 헤더 확인 (GET /security/headers)

          
현재 연결된 클라이언트 요청에 포함된 보안 헤더 정보를 분석합니다.

          
          

        

        

          
EdgeForge (GET /edgeforge)

          
Edge 네트워크에서의 응답 처리 성능을 확인하는 평가 테스트입니다.
