API 서비스

다양한 유틸리티 API를 테스트하고 사용할 수 있습니다.

API 문서 보기

IP Info

요청자의 IP 주소 및 지리/네트워크 정보 조회

전체 IP 정보 (GET /ip)

접속한 클라이언트의 상세 IP 정보를 일반 사용자가 읽기 쉬운 요약으로 보여줍니다.


        

        

          
단순 IP 주소 (GET /ip/simple)

          
클라이언트의 IP 주소만 평문(텍스트)으로 반환합니다.

          
          

        

      

    


    
    

      
Encode/Decode

      
다양한 형식의 인코딩/디코딩 (Base64, URL, HTML, Hex 등)

      

        

          
인코딩 (GET /encode)

          
문자열을 다양한 포맷으로 인코딩할 수 있으며, 현재는 Base64 예시를 제공합니다.

          

            
            
          

          

        

        

          
디코딩 (GET /decode)

          
다양한 포맷의 인코딩 데이터를 디코딩할 수 있으며, 현재는 Base64 예시를 제공합니다.

          

            
            
          

          

        

      

    


    
    

      
QR Code

      
QR 코드 생성 (SVG/JSON, WiFi·vCard·이메일 등 지원)

      

        
텍스트 기반 QR 생성 (GET /qr)

        
텍스트, URL 등 입력값을 QR 코드로 생성합니다. SVG 기본 출력이며 JSON 포맷도 지원합니다.

        

          
          
        

        

      

    


    
    

      
Dead Drop

      
한 번만 읽을 수 있는 임시 비밀 메시지 저장소

      

        

          
메시지 저장 (POST /store)

          
내용을 암호화하여 서버에 임시 저장하고 고유 ID를 발급받습니다.

          

            
            
          

          

        

        

          
메시지 열람 (GET /read/:id)

          
발급받은 ID를 통해 보관된 메시지를 열람합니다. (열람 즉시 파기)

          

            
            
          

          

        

      

    


    
    

      
Security API / EdgeForge API (Beta)

      

        

          
Security API (GET /security/headers)

          
HTTP 보안 헤더 분석 및 등급 산출. 확인할 URL을 입력해 분석할 수 있습니다.

          

            
            
          

          

        

        

          
EdgeForge API (Beta) (GET /edgeforge)

          
테스트를 위한 가짜(Mock) JSON 응답 생성기
